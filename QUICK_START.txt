🎮 STORMBREAKER GAMING KERNEL - QUICK START
============================================

For: Redmi Note 9 Pro (miatoll) + Infinity X 4.0 + Free Fire Esports

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: PREPARE YOUR PC
─────────────────────────────────────────────────────────────────────

Linux/WSL:
  sudo apt install -y build-essential bc bison flex llvm clang

macOS:
  brew install llvm coreutils

Download:
  git clone https://github.com/SkRiaz593/PurrX-Curtana-Kernel.git
  cd PurrX-Curtana-Kernel
  git checkout gaming-daily-toggle

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: EDIT KERNEL CONFIG
─────────────────────────────────────────────────────────────────────

File: arch/arm64/configs/vendor/xiaomi/miatoll_defconfig

Find and edit these lines:

  1. Change:
     CONFIG_LRU_GEN=y → # CONFIG_LRU_GEN is not set
     CONFIG_LRU_GEN_ENABLED=y → # CONFIG_LRU_GEN_ENABLED is not set

  2. Change:
     # CONFIG_CPU_BOOST is not set → CONFIG_CPU_BOOST=y
     Add: CONFIG_CPU_BOOST_INPUT_MS=500
     Add: CONFIG_CPU_BOOST_INPUT_FREQ_GB=1500000

  3. Change:
     CONFIG_MEMCG_SWAP=y → # CONFIG_MEMCG_SWAP is not set

  4. Change:
     CONFIG_ZSWAP=y → # CONFIG_ZSWAP is not set

Save file.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3: BUILD KERNEL (30 minutes)
─────────────────────────────────────────────────────────────────────

  export ARCH=arm64
  export CROSS_COMPILE=aarch64-linux-gnu-
  export LLVM=1 LLVM_IAS=1
  
  make distclean
  make vendor/xiaomi/miatoll_defconfig
  make -j$(nproc)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4: CREATE FLASHABLE ZIP
─────────────────────────────────────────────────────────────────────

  cp arch/arm64/boot/Image.gz-dtb AnyKernel3/
  cd AnyKernel3
  zip -r9 Stormbreaker-Gaming.zip * -x .git README.md *placeholder
  cd ..

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 5: FLASH TO PHONE
─────────────────────────────────────────────────────────────────────

  adb push AnyKernel3/Stormbreaker-Gaming.zip /sdcard/
  adb reboot recovery

In recovery:
  Install → Select ZIP → Stormbreaker-Gaming.zip → Swipe to flash
  Reboot system

Wait 3 minutes for first boot...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 6: VERIFY & USE
─────────────────────────────────────────────────────────────────────

Verify:
  adb shell uname -a
  adb shell cat /sys/kernel/mm/lru_gen/enabled  (should be 0)

Before Free Fire:
  adb shell /data/gaming_mode/gaming_mode.sh

After gaming (daily mode):
  adb shell /data/gaming_mode/daily_mode.sh

Monitor performance:
  adb shell /data/gaming_mode/monitor.sh
